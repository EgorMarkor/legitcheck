Политика конфиденциальности

Редакция от 29.05.2026

1. Общие положения

Настоящая Политика конфиденциальности описывает, какие данные сервис LegitCheck / Checker собирает, зачем они используются, как хранятся и какие права есть у пользователя.

Используя приложение, Telegram WebApp, бота, сайт или мобильные функции сервиса, пользователь подтверждает, что ознакомился с этой Политикой.

Если пользователь не согласен с условиями обработки данных, ему необходимо прекратить использование сервиса и обратиться в поддержку для решения вопроса по уже созданным данным.

2. Какие данные мы обрабатываем

Сервис обрабатывает данные, которые нужны для авторизации, оформления проверки товара, выдачи вердикта, оплаты и поддержки пользователя.

  • данные Telegram-профиля: Telegram ID, имя, username, аватар и данные авторизации Telegram WebApp;
  • email, если пользователь входит в сервис или подтверждает доступ через email;
  • фотографии товаров, бирок, упаковки, серийных номеров и других деталей, которые пользователь загружает для проверки;
  • информация о проверке: категория товара, бренд, модель, комментарий пользователя, код вердикта, статус вердикта, дата создания;
  • платёжные данные в объёме, необходимом для фиксации оплаты: сумма, статус платежа, внутренний идентификатор и идентификатор платёжного провайдера;
  • технические данные: IP-адрес, данные устройства и браузера, cookies, localStorage, sessionStorage, журналы ошибок и события безопасности.

Мы не просим пользователя загружать документы, паспортные данные или лишнюю личную информацию. Если такие данные случайно попали на фото товара, они могут быть обработаны вместе с загруженным изображением.

3. Зачем используются данные

  • для создания и защиты учётной записи пользователя;
  • для приёма фотографий и передачи их экспертам на проверку;
  • для формирования, хранения и показа результата проверки;
  • для добавления дополнительных фото к уже созданному вердикту;
  • для обработки оплаты, возвратов, промокодов и баланса;
  • для отправки уведомлений, кодов входа и ответов поддержки;
  • для предотвращения мошенничества, технических сбоев и несанкционированного доступа;
  • для улучшения интерфейса, стабильности и качества работы сервиса.

4. Передача данных

Сервис не продаёт персональные данные пользователей.

Данные могут передаваться только в объёме, необходимом для работы сервиса:

  • экспертам и сотрудникам, которые выполняют проверку товара и обрабатывают обращения;
  • Telegram, если пользователь использует Telegram-бота или Telegram WebApp;
  • платёжному провайдеру для проведения и подтверждения платежей;
  • почтовому сервису для отправки email-кодов и служебных уведомлений;
  • хостинг-провайдерам, облачным хранилищам, аналитическим и техническим сервисам, которые обеспечивают работу приложения;
  • государственным органам, если передача требуется по закону или официальному запросу.

Если сторонний сервис обрабатывает данные на своей стороне, его правила конфиденциальности могут применяться дополнительно к этой Политике.

5. Хранение и защита

Данные хранятся столько, сколько необходимо для работы сервиса, исполнения обязательств перед пользователем, финансового учёта, защиты прав сервиса и соблюдения требований закона.

Фотографии и вердикты сохраняются, чтобы пользователь мог открыть историю проверок и подтвердить результат ранее оказанной услуги.

Для защиты данных используются ограничение доступа, авторизация пользователей, серверное хранение файлов и технические меры против несанкционированного доступа. При этом ни один способ передачи или хранения данных в интернете не может быть абсолютно безопасным.

6. Cookies и локальное хранение

Сервис может использовать cookies, localStorage и sessionStorage для авторизации, восстановления сессии, хранения служебного токена, защиты аккаунта и корректной работы интерфейса.

Отключение этих механизмов в браузере может привести к тому, что часть функций приложения будет работать некорректно.

7. Права пользователя

Пользователь может обратиться в поддержку, чтобы:

  • получить информацию о своих данных;
  • исправить неточные данные;
  • запросить удаление аккаунта, фотографий или истории проверок, если это не противоречит закону и обязательствам сервиса;
  • отозвать согласие на обработку данных;
  • задать вопрос по обработке данных или безопасности аккаунта.

После удаления части данных некоторые функции сервиса, включая доступ к истории вердиктов, могут стать недоступны.

8. Данные несовершеннолетних

Сервис не предназначен для самостоятельного использования лицами, которые не достигли возраста, позволяющего самостоятельно давать согласие на обработку персональных данных. Если сервисом пользуется несовершеннолетний, ответственность за такое использование несёт его законный представитель.

9. Изменение Политики

Сервис может обновлять эту Политику. Актуальная версия публикуется в приложении. Новая редакция применяется с момента публикации, если в ней не указан другой срок вступления в силу.

Продолжение использования сервиса после обновления Политики означает согласие пользователя с новой редакцией.

10. Контакты

По вопросам обработки персональных данных, удаления аккаунта, доступа к данным или безопасности обратитесь в раздел «Поддержка» в приложении.

Для email-обращений можно использовать адрес: checkercheckerlegit@gmail.com.
